# 장치 등록부

relay가 붙이는 장치는 모두 '모델이 혼자 못 한다'는 가설이다(philosophy 원칙 5). 끄는 조건이 없으면 들어오지 못한다. 바닥은 가설이 아니어서 꺼 보지 않는다.

상태: 꺼짐 / 그림자(기록만) / 알림(보이기만) / 관문(결론에 들어감) / 바닥

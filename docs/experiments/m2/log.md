# M2 평가 기록

규약(`protocol.md`)을 고정하기 전과 뒤에 정한 것, 바꾼 것, 본 것을 차례로 적는다.

## 2026-11-04 고정 전

- 도구를 만들며 실제 Claude로 시범을 돌렸다(시나리오 10: relay3 4회, cli 1회). 결과는 판정에 넣지 않는다.
- 시범에서 드러난 것과 처리:
  1. 레포에 `.relay/quality.json`이 없으면 v3 증거가 비고 관문이 늘 사람 머지 → 앱에 품질 기준 초안 제안(V20), 초안에 기본 자동 조건(V19), 평가에 `--quality-overlay`.
  2. PR이 없으면 리뷰가 [끝내기] 때만 돌고 곧바로 끝나 리뷰가 코드에 닿을 길이 없음 → 끝내기 두 단계(V18).
  3. MCP 도구가 사람을 기다리는 동안 Claude Code의 시계가 돌아 사람 역할이 최대 120초 늦게 깸 → 깨우기에서 시계를 가림(모든 쪽).
  4. 리뷰 토큰이 세지지 않음(`claude -p --no-session-persistence`) → 앱이 usage를 남기고 평가가 더함. 두 앱 모두 앱의 `claude -p`를 더하게 맞춤.
  5. 스크린샷의 요소 번호가 가끔 빠짐(6/30) → 두 프레임 기다리고 다시 찍기.
- 시나리오 10의 시범을 보고 `guides/relay3.md`에 끝내기 안내를 고쳤다. 측정 시나리오의 결과를 보고 설명서를 고친 것이므로 여기 적는다.

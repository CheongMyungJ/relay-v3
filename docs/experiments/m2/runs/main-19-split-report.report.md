### 사람 역할의 말

- [relay3#1 좋음] 계약에 예시 입력과 출력, 근거, 비목표가 먼저 나와서 동작이 그대로라는 근거를 승인 전에 볼 수 있었다. 증거 탭에서 줄마다 판정을 보여 준 것도 좋았다.

- [relay3#2 좋음] 계약 단계에서 세션이 정렬 순서와 0원·NaN 처리 같은 현재 동작을 먼저 물어 줘서, 동작을 그대로 두는 리팩터링이라는 점이 일찍 고정됐다. 변경 diff도 원래 로직을 옮긴 것이 바로 보였다.
- [relay3#2 불편] 계약 예시 표기 문제("NaN→NaN", 따옴표 누락) 때문에 증거가 '못 미침'으로 몇 번 나와 계약 수정과 재측정을 반복해야 했다. 리팩터링의 본질인 동작 보존과 상관없는 일에 시간을 썼다. 증거 재측정이 낡았는지 반영됐는지 구분하기도 어려웠다. C5는 기준에 시험이 없어 구조적으로 충족될 수 없었다.
- [relay3#3 좋음] 계약 단계에서 요약 모양과 0원 행 처리 같은 결정을 미리 물어 주고, 옛 코드와 새 코드 5007건 출력 비교로 동작이 그대로라는 근거를 보여 준 점이 좋았다.

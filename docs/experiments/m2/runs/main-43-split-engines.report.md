- [relay3#1 좋음] 계약 단계에서 필요한 것만 골라 물었다. 증거 탭이 '예시 자료가 승인된 예시와 다름' 같은 구체적인 이유를 보여 줬고, 독립 리뷰가 실제 버그(끝 공백, javascript: 링크)를 잡아냈다.

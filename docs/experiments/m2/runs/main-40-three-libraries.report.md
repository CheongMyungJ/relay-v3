### 사람 역할의 말

- [relay3#1 좋음] 계약을 먼저 보고 승인하는 흐름과, 끝내기 때 독립 리뷰가 실제 허점(1e21, 앞자리 0, 단독 CR 등)을 짚어 준 점이 좋았다. 모듈마다 브랜치를 따로 두고 싶다는 선호도 세션이 처음부터 반영해 범위를 csv만으로 좁혔다.
- [relay3#1 불편] 세 개를 한 번에 맡겼는데 한 Work에는 하나만 담겨 새 Work를 두 번 더 직접 만들어야 했다. 증거가 '예시 자료가 승인된 예시와 다름'이라고 못 미침을 판정해도 세션은 이유를 몰라서, 증거 탭의 사유를 내가 옮겨 말해야 했다. 다른 Work를 보고 오면 끝내기 확인 상자가 사라져 끝내기와 리뷰를 다시 돌려야 했다.
- [relay3#2 좋음] 계약을 먼저 보고 승인하는 흐름이 좋았다. 질문이 구체적이었고, 모듈마다 브랜치를 따로 두고 싶다는 내 뜻을 세션이 먼저 짚어 줬다. 끝내기 전에 독립 리뷰가 지적을 보여 줘서 점검하기 쉬웠다.
- [relay3#2 불편] 세 모듈을 한 번에 맡겼는데 도구가 알아서 나누지 못해서, 나머지 두 Work를 내가 직접 만들어야 했다. 또 예시 파일 표기 차이로 전 줄이 '못 미침'으로 떴고, 지킴 줄 증거와 시험 개수 래칫이 서로 부딪쳐 한쪽을 골라야 했다. 이 부분이 헷갈렸다.

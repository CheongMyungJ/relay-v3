- [relay3#2 좋음] 원인 두 가지를 먼저 설명하고 어디까지 고칠지 물었다. 계약에 예시가 있어서, 푸시도 넣어 달라는 요청이 바로 반영됐다.

- [relay3#3 좋음] 계약에 예시 입력과 출력이 있었고, 메일과 푸시 둘 다 한 번만 가는지 보여 주는 시험이 있었다. 원인을 짚고 나서 동작을 물어봐서 방향을 내가 정할 수 있었다.
- [relay3#3 불편] 첫 계약에는 메일만 있고 푸시가 빠져 있어서 내가 추가를 요청해야 했다. 끝낼 때는 '머지 없이 끝남'과 '채운 자동 조건 없음', 리뷰 지적 1개가 한꺼번에 떠서 무슨 뜻인지 바로 알기 어려웠다.
- [relay3#4 좋음] 에이전트가 원인 두 가지를 먼저 찾아서 결정이 필요한 한 가지만 물었다. 계약에 메일과 푸시 예시가 나뉘어 있었고, 기준 커밋에서는 실패하고 수정 후에는 통과하는 줄 판정이 나와서 믿기 쉬웠다.

### 사람 역할의 말

- [relay3-m21#1 좋음] 세 모듈을 요청 하나로 맡겼는데 도구가 알아서 단위로 나눴고, 단위마다 브랜치와 증거가 따로 생겼다. 계약에 예시와 근거가 보여서 승인하기 쉬웠다.
- [relay3-m21#1 불편] 단위별 리뷰가 따로 돌아서 끝내기 전에 여러 번 기다려야 했다. 질문에서 추천 선택지가 내가 아는 규칙과 달라 직접 써서 답해야 한 적도 있었다.
- [relay3-m21#2 좋음] 요청 한 번으로 세 모듈이 단위별 브랜치로 알아서 나뉘었다. 계약에 예시가 있어서 승인하기 전에 formatKrw 소수 처리가 내가 아는 것과 다른 것을 잡아 고칠 수 있었다.
- [relay3-m21#2 불편] 리뷰와 증거 재기를 기다리는 시간이 길었다. 끝내기를 눌렀는데 리뷰가 지적하고 세션이 고치고 다시 리뷰가 도는 과정을 반복해서 거쳤다. 마지막 지적은 계약 밖 검사였는데 내가 넘기라고 한 쪽이어서 헷갈렸다.
- [relay3-m21#3 좋음] 세션이 모듈별 브랜치를 먼저 물어보고 계약에 반영했다. 계약 탭에서 예시와 규칙을 확인한 뒤 승인할 수 있어서 안심이 됐다.
- [relay3-m21#3 불편] 끝내기를 누르니 리뷰를 기다리느라 한참 걸렸고, 열린 것 6개가 한꺼번에 떴다. 대부분 테스트 보강이라 '그래도 끝내기'를 눌러야 하는지 잠깐 망설였다. 모듈별 브랜치가 따로 push되지 않은 채 끝나는 점도 조금 아쉬웠다.
- [relay3-m21#4 좋음] 요청 하나로 세 모듈을 맡겼더니 도구가 모듈별 단위와 브랜치로 알아서 나눴다. 계약에 예시가 있어서 내가 아는 규칙(소수 버림 등)이 어긋난 것도 바로 잡을 수 있었다.
- [relay3-m21#4 불편] 끝내기를 누르면 리뷰가 단위마다 따로 돌아 기다림이 길었다. 다시 끝내기를 누르면 새 리뷰 지적이 또 나와서 어디서 멈출지 정하기가 애매했다.
- [relay3-m21#5 좋음] 요청 하나로 세 모듈을 맡겼더니 세션이 알아서 모듈별 브랜치로 나눠 줬고, 계약 단계에서 경계 규칙을 하나씩 물어 내 선호가 잘 반영됐다.
- [relay3-m21#5 불편] 단위별 증거와 리뷰가 제각각 낡았다고 뜨고 리뷰가 새 지적을 계속 내서 상태 파악이 번거로웠다. 패널이 길어 스크롤도 많이 해야 했다. 끝내기도 리뷰를 기다리느라 오래 걸렸다.
